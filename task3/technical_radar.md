### Для информации:
*Распределение по цветам:*

- ADOPT (Зеленый, внешнее кольцо) — «Принять». Технологии, которые нужно активно внедрять.
- TRIAL (Светло-зеленый, следующее кольцо) — «Пробовать». Пилотные проекты.
- HOLD (Красный, внутреннее кольцо) — «Держать на расстоянии». Высокий риск, лучше не использовать.

## Бизнес-сценарии для каждой технологии
| Название технологии | Поддерживаемый бизнес-сценарий |
| --- | --- |
| ClickHouse (Managed) | Сверхбыстрое построение аналитической отчетности (миллисекунды вместо часов). |
| PostgreSQL (HA Cluster) | Надежное и масштабируемое хранение транзакционных данных клиник и финтеха. |
| MinIO / Cloud Object Storage | Дешевое и надежное хранение тяжелых медицинских снимков (КТ/ МРТ). |
| MS SQL Server 2008 | Legacy. Полный отказ из-за рисков безопасности и низкой производительности. |
| Kubernetes (Managed K8s) | Масштабирование микросервисов финтеха и клиник под нагрузкой. |
| Terraform | Автоматизация развертывания облачной инфраструктуры (IaC), обеспечение идентичности тестовых и прод-сред. |
| Apache Kafka | Асинхронный обмен данными между доменами, повышение отказоустойчивости системы. |
| ESB Apache Camel (Monolithic) | Legacy. Уход от синхронной централизованной точки отказа. |
| Apache Superset / Custom Portal | Портал самообслуживания аналитики (Self-Service) без написания сложного SQL-кода пользователями. |
| Golang / Java / Python | Быстрая разработка надежных бэкенд-сервисов и моделей искусственного интеллекта. |
| PowerBuilder | Legacy. Полный отказ, так как стек тормозит развитие UI/UX и наем инженеров. |
